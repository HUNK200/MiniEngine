MiniEngine —— 终端里的小游戏 demo（v0.4「看得清」· 2026-10-16 · Windows x64）

■ 怎么开始
  1) 双击「开始试玩.cmd」
  2) 看到标题屏后按 ENTER 开始
  3) 想退出：按 Q（或直接关窗口）

■ 按键
  W A S D / 方向键    移动（八向）
  SPACE               开火（弹药有限，击杀一个返还 1 发）
  ENTER               标题屏开始
  ESC                 暂停 / 恢复；GAME OVER 时回标题屏
  R                   GAME OVER 后立刻重开（世界重铺）
  F7                  敌人状态面板（逐敌 state / distance / tile）
  T                   帧时间面板（能看出"这一帧渲染花了多少 ms"）
  F2                  几何层：墙与实体占格用底色标出来（字形一个都不变）
  F4                  把一份调试快照写进 miniengine_debug.log
  Q                   退出

■ 这是什么
  一个用 C++20 + 终端 ANSI 转义序列写的 2D 小引擎（没有图形库：画面就是字符与颜色，
  只重画变化的行），上面跑一个波次射击小游戏：会追会打的敌人、射击与击杀、HP/弹药/波次、
  死亡与重开。当前 220 条单元用例全绿；S11 阶段还做了 5 场"故意改坏、看测试响不响"的
  反向验证（3 场红 / 1 场绿 / 1 场崩）。

■ 已知限制（照实说）
  1) 只支持 Windows x64。**不需要**装 Visual Studio 或 CMake，也不需要 VC++ 可再发行
     组件（这个 exe 用的是静态 CRT，依赖表里只有系统 DLL）。
  2) 终端太小会挤：窗口小于 100×30 时，程序会在启动时尝试自动放大。
     · 在**经典控制台**里有效；
     · 在 Windows Terminal / VS Code 内置终端（ConPTY）里**改不动** —— 这是 ConPTY 的
       限制（窗口归终端客户端管），不是程序坏了。那种情况下请手动拖大（建议 ≥100×30）。
  3) ConPTY 系终端收不到 key-up ⇒「按住移动」会退化成「按一次走一帧」。
     启动器优先用 conhost（经典控制台），在那里长按是正常的。
  4) 这个 exe 没有数字签名：首次运行 Windows 可能提示「Windows 已保护你的电脑」——
     点「更多信息」→「仍要运行」。

■ 出问题了怎么反馈（最有用的方式）
  1) 进游戏后按 F4 **两次**（把当前状态写进 miniengine_debug.log）
  2) 把 miniengine_debug.log 发回来，并说明：你用的是哪个终端、窗口多大、你做了什么
     （日志每行都有 [时间][级别] 前缀；`version` 那行能看到版本号）
