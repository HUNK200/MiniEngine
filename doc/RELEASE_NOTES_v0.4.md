# MiniEngine v0.4「看得清」—— 终端里的小游戏 demo

> **一句话**：一个用 C++20 + 终端 ANSI 转义序列写的 2D 小引擎，上面跑一个波次射击小游戏。
> 没有图形库 —— 画面就是字符与颜色，而且只重画**变化的行**（脏行差分）。
> 这个包里是**已经编译好的 exe**：不需要 Visual Studio、不需要 CMake、也不需要 VC++ 可再发行组件。

---

## 1. 怎么跑（三步）

1. 下载 `MiniEngine-Demo-v0.4.0-windows-x64.zip`，**解压到任意目录**
2. 双击 **`开始试玩.cmd`**（它会用经典控制台启动游戏 —— 见下面"已知限制"第 2/3 条）
3. 看到标题屏后按 **`ENTER`** 开始；想退出按 **`Q`**

> 包里还有一个 `玩法与已知限制.txt`，内容和下面几节一样（离线可读）。

## 2. 键位

| 键 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 移动（八向） |
| `SPACE` | 开火（弹药有限，击杀一个返还 1 发） |
| `ENTER` | 标题屏开始 |
| `ESC` | 暂停 / 恢复；`GAME OVER` 时回标题屏 |
| `R` | `GAME OVER` 后立刻重开（世界重铺） |
| `F7` | 敌人状态面板（逐敌 `state / distance / tile`） |
| `T` | 帧时间面板 —— 能看出"这一帧渲染花了多少 ms" |
| `F2` | 几何层：墙与实体占格用**底色**标出来（字形一个都不变） |
| `F4` | 把一份调试快照写进 `miniengine_debug.log` |
| `Q` | 退出 |

一局的节奏：标题屏 → `ENTER` 刷第 1 波 3 个敌人 → 被追打 / 开火反击 → `ESC` 暂停（**世界完全冻住**，
连波次的喘息倒计时都停）→ 掉血归零 → `GAME OVER` → `R` 重开。波次 `3 → 4 → 5 …` 封顶 8；弹药 18。

## 3. 这个版本有什么（v0.4「看得清」）

这一版的主题是**"看得清"** —— 让性能与状态从"感觉"变成"数字"：

- `T`：**Debug Overlay**（右上角实时面板）= 引擎帧数据 + 7 段分段耗时表 + 游戏计数
- `PROFILE_SCOPE`：引擎侧 5 段（`Frame` / `Game.Update` / `Game.Render` / `StatsBar` / `Present`）
  + 游戏侧 2 段（`Game.AI` / `Game.Bullets`），120 帧滑动窗口
- `F2`：几何层（底色通道，不碰字符）· `F7`：敌人列表 · `F4`：分级日志

**验证情况（照实说）**：**220 条单元用例全绿**；S11 阶段做了 **5 场"故意改坏、看测试响不响"的反向验证**
（3 场红 / 1 场绿 / 1 场崩 —— 绿的那场如实登记为"无守卫且不需要"）；**19 条人眼验收**全部通过。
判断过程与所有偏差记录在 `doc/` 里（这个仓库**文档比生产代码多**）。

## 4. 已知限制（照实说）

1. **只支持 Windows x64**。exe 用静态 CRT 编译，依赖表里只有系统 DLL（不需要 VC++ 可再发行组件）。
2. **终端太小会挤**：窗口小于 **100×30** 时，程序会在启动时尝试自动放大。
   · 在**经典控制台**里有效；· 在 Windows Terminal / VS Code 内置终端（ConPTY）里**改不动** ——
   这是 ConPTY 的限制（窗口归终端客户端管），不是程序坏了。那种情况下请手动把窗口拖大（建议 ≥100×30）。
3. **ConPTY 系终端收不到 key-up** ⇒「按住移动」会退化成「按一次走一帧」。
   启动器优先用 `conhost`（经典控制台），在那里长按正常。
4. **没有数字签名**：首次运行 Windows 可能提示「Windows 已保护你的电脑」——
   点「更多信息」→「仍要运行」。
5. 实体之间**没有推挤**：两只敌人可以叠在同一格，屏幕上只画得出一个 `E`（有意不做，见台账 `C12`）。

## 5. 出问题了怎么反馈（最有用的方式）

1. 进游戏后按 **`F4` 两次**（会把当前状态写进 `miniengine_debug.log`）
2. 把 `miniengine_debug.log` 发回来，并说明：**你用的是哪个终端、窗口多大、你做了什么**

日志每行都有 `[时间][级别]` 前缀；`version` 那行是版本号，`canvas=` 是当时的画布尺寸 ——
这两条能把"你那边到底跑的是什么"钉死。

| 项 | 值 |

| 版本串 | `0.4.0-dev`：按仓库约定 `-dev` 表示"**已达成 v0.4、树在往 v0.5 走**"，与 tag `v0.4.0` 不矛盾 |
| 校验 | SHA256: `4af8d1d5489fa24337cc1d41bf46dfd284b452d8e0926a28aeffff75b4946354`（= 已上传资产，2026-10-16 核过） |

**从源码自己构建**（需要 Windows + MSVC 2022 + CMake ≥ 3.20）：

```powershell
cmake -S . -B build
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure     # 220 条用例
.\build\bin\Debug\MiniEngine.exe
```

**自己打一个 demo 包**：

```powershell
powershell -File tools\pack_demo.ps1        # ⇒ dist\MiniEngine-Demo-v0.4.0-windows-x64.zip
```
